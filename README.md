# Кредитный скоринг

Этот проект предназначен для построения модели кредитного скоринга, которая предсказывает вероятность дефолта заемщика на основе данных. 

## Описание

Сравнил CatBoost, XGBoost с разными гиперпараметрами, для поиска которых использовалась Optuna. Сравнил их по метрике Roc-Auc. Задание с хакатона: Alfa-Hack.
